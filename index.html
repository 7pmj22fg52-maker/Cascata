Mani

Auto: la mano suona da sola. Tu: il brano si ferma e aspetta le tue note. Off: la mano sparisce.

Tracce del file
Sensibilità

Metti il telefono vicino alla tastiera. La barra deve muoversi quando suoni e restare ferma quando c'è silenzio: se si muove anche col silenzio, abbassa la sensibilità.

Brano d'esempio caricato. Premi play e guarda le note cadere, oppure apri un file MIDI tuo.

Dove trovo i file MIDI?

Cerca il titolo del brano seguito da «midi» e scarica il file sul telefono. Controlla la licenza: per studiare da soli di solito va bene. Se il file ha una sola traccia, le note sotto il Do centrale vanno alla mano sinistra.
